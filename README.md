# Derecho Laboral — Sitio web educativo

**Autor:** Jhoger Guerrero
**Año:** 2026
**Tema:** Derecho Laboral

Página web educativa, creativa y responsiva sobre **Derecho Laboral**, dividida por
secciones, con diseño profesional en tono verde esmeralda (#006B62), ilustraciones
minimalistas en SVG y animaciones al hacer scroll.

## Secciones

1. Inicio
2. Concepto — ¿Qué es el Derecho Laboral?
3. Principios fundamentales
4. El contrato de trabajo (tipos y elementos)
5. Derechos del trabajador
6. Obligaciones del empleador
7. Jornada, salario y seguridad social
8. Preguntas frecuentes
9. Contacto

## Tecnologías

- HTML5 + CSS3 (un solo archivo, autocontenido)
- JavaScript (animaciones, menú, acordeón, contadores)
- Tipografías: Fraunces + Inter (Google Fonts)

## Ver el sitio

Publicado con GitHub Pages. Abre `index.html` en cualquier navegador o visita el sitio publicado.
